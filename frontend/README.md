# Frontend OCR Application

This directory contains the Vue.js frontend for the Libras Sign Writing OCR application.

## Prerequisites

Before you begin, ensure you have the following installed on your system:
- [Node.js](https://nodejs.org/) (which includes npm)

## Project Setup

1. **Navigate to the frontend directory:**
   ```sh
   cd frontend
   ```

2. **Install dependencies:**
   This command will download and install all the necessary packages defined in `package.json`.
   ```sh
   npm install
   ```

## Compiles and hot-reloads for development

Once the dependencies are installed, you can start the local development server.
```sh
npm run serve
```
The application will be available at `http://localhost:8080/` by default. The server will automatically hot-reload if you make any changes to the source files.

## Lints and fixes files

This project is set up with ESLint to maintain code quality. To run the linter, use the following command:
```sh
npm run lint
```
